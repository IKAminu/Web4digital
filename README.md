# Web7 Digital

The Web7 Digital company website, built with React, TypeScript, Vite and React Three Fiber.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Web7 Digital is the current brand; Web4 is retained only as a temporary transition reference for approximately three months.\n\nThe site is configured for deployment to GitHub Pages from the `main` branch using GitHub Actions. The production build uses Vite's relative base path so it works at `/Web7 Digital/` and on a custom domain.
