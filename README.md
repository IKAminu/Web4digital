# Web4

The Web4 company website, built with React, TypeScript, Vite and React Three Fiber.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The site is configured for deployment to GitHub Pages from the `main` branch using GitHub Actions. The production build uses Vite's relative base path so it works at `/Web4digital/` and on a custom domain.
