# Web4 brand assets

Upload the three brand assets into this folder using these exact filenames:

| Asset | Filename | Format | Used on the website |
|---|---|---|---|
| Founder portrait | `ik-aminu.webp` | WEBP | Founder card in the About section, replacing the IK monogram |
| RouteHQ logo | `routehq-logo.svg` | SVG | RouteHQ logo in the product dashboard preview |
| Web4 logo | `web4-logo.svg` | SVG | Web4 logo in the website header and footer |

## Image guidance
- Founder portrait: square crop, ideally 800 × 800 px or larger. A clear head-and-shoulders portrait works best.
- Logos: export clean SVGs with a transparent background and a sensible viewBox. Avoid embedding raster images inside the SVG.
- The Web4 logo should be legible on the site's dark navy background. The RouteHQ logo should also be suitable for the dark product-preview header. If your logo files are dark variants, export light/white versions for these placements.

The website code is already wired to these paths. Until an asset is uploaded, its existing text/monogram fallback remains visible. No code edits are needed after uploading files with these names.
